Fungsi Eksponensial an

Tiga kondisi utama dalam menghitung fungsi eksponensial berdasarkan nilai pangkat n.

📌

Definisi

Fungsi eksponensial f(n) = an didefinisikan sebagai perkalian berulang bilangan basis a sebanyak n kali. Nilai pangkat n menentukan cara perhitungan yang digunakan.

Kondisi 1
0️⃣

Pangkat Nol

a0 = 1
Syarat: n = 0

Berdasarkan definisi matematika, setiap bilangan bukan nol yang dipangkatkan 0 selalu menghasilkan nilai 1. Ini adalah aksioma dasar dalam teori eksponen.

✦ Contoh Soal
20 → 1
70 → 1
(-5)0 → 1
1000 → 1
⚠️ Catatan: 00 bersifat tidak terdefinisi (indeterminate form)
Kondisi 2
➕

Pangkat Positif

an = a × a × … × a
Syarat: n > 0

Apabila pangkat n bernilai positif, maka an dihitung dengan mengalikan basis a dengan dirinya sendiri sebanyak n kali secara berulang.

✦ Contoh Soal
23 → 2×2×2 = 8
34 → 3×3×3×3 = 81
52 → 5×5 = 25
(-2)3 → (-2)×(-2)×(-2) = -8
Kondisi 3
➖

Pangkat Negatif

a-n = 1 / an
Syarat: n < 0

Apabila pangkat n bernilai negatif, maka hasilnya diubah menjadi bentuk pecahan: pembilang 1 dibagi hasil perpangkatan positifnya.

✦ Contoh Soal
2-3 = 1/23 = 1/(2×2×2) = 1/8 = 0.125
3-2 = 1/32 = 1/(3×3) = 1/9 ≈ 0.111
5-1 = 1/51 = 1/5 = 0.2
⚠️ Catatan: Jika basis a = 0, maka 0-n tidak terdefinisi
