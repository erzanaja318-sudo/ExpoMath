Fungsi Eksponensial an

Pemahaman mendalam mengenai konsep, bentuk umum, sifat, dan karakteristik fungsi eksponensial dalam matematika.

📌

Pengertian & Bentuk Umum

Fungsi eksponensial adalah fungsi non-linear yang memetakan setiap bilangan real x ke nilai ax, di mana a merupakan konstanta bilangan positif yang bertindak sebagai basis (bilangan pokok), dan variabel bebasnya bertindak sebagai eksponen (pangkat).

Secara matematis, bentuk umum fungsi eksponensial dituliskan sebagai:

f(n) = an  atau  y = an

⚠️ Syarat Penting Basis (a):

  • a > 0 (Basis harus berupa bilangan positif agar menghasilkan nilai riil yang konsisten).
  • a ≠ 1 (Jika basis bertingkat 1, maka nilainya akan selalu konstan 1n = 1, sehingga tidak lagi membentuk kurva eksponensial).
📈

Karakteristik & Sifat Grafik

Pertumbuhan fungsi eksponensial sangat berbeda dengan pertumbuhan linear. Berdasarkan nilai basisnya, grafik eksponensial dibagi menjadi dua kategori utama:

  • Pertumbuhan Eksponensial (Exponential Growth): Terjadi jika nilai a > 1. Grafik akan melengkung naik secara ekstrem dari kiri bawah ke kanan atas. Contoh fenomena nyata: Pembelahan sel biologi, pertumbuhan populasi, atau bunga majemuk perbankan.
  • Peluruhan Eksponensial (Exponential Decay): Terjadi jika nilai basis berupa pecahan antara nol dan satu (0 < a < 1). Grafik akan melengkung turun secara ekstrem dari kiri atas ke kanan bawah. Contoh nyata: Peluruhan zat radioaktif atau penyusutan nilai aset ekonomi.

*Catatan: Grafik fungsi eksponensial tidak akan pernah menyentuh sumbu X (nilai hasil y selalu > 0). Garis sumbu X ini bertindak sebagai Asimtot Datar.

Pangkat Nol

a0 = 1
Syarat: n = 0

Berdasarkan definisi matematika, setiap bilangan bukan nol yang dipangkatkan 0 selalu menghasilkan nilai 1. Ini adalah aksioma dasar dalam teori eksponen.

✦ Contoh Soal
20 → 1
70 → 1
(-5)0 → 1
1000 → 1
⚠️ Catatan: 00 bersifat tidak terdefinisi (indeterminate form)
Kondisi 2
➕

Pangkat Positif

an = a × a × … × a
Syarat: n > 0

Apabila pangkat n bernilai positif, maka an dihitung dengan mengalikan basis a dengan dirinya sendiri sebanyak n kali secara berulang.

✦ Contoh Soal
23 → 2×2×2 = 8
34 → 3×3×3×3 = 81
52 → 5×5 = 25
(-2)3 → (-2)×(-2)×(-2) = -8
Kondisi 3
➖

Pangkat Negatif

a-n = 1 / an
Syarat: n < 0

Apabila pangkat n bernilai negatif, maka hasilnya diubah menjadi bentuk pecahan: pembilang 1 dibagi hasil perpangkatan positifnya.

✦ Contoh Soal
2-3 = 1/23 = 1/(2×2×2) = 1/8 = 0.125
3-2 = 1/32 = 1/(3×3) = 1/9 ≈ 0.111
5-1 = 1/51 = 1/5 = 0.2
⚠️ Catatan: Jika basis a = 0, maka 0-n tidak terdefinisi
